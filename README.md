# Tea Project — Интерактивная карта чайных плантаций

Сервис для любителей чая, где можно исследовать сорта чая со всего мира через интерактивную карту.

---

## 📌 О проекте

**Идея:**  
Главная особенность — большая карта, на которой можно увидеть, где культивируется тот или иной сорт чая. Пользователь выбирает точку на карте и получает подробную информацию. Зарегистрированные пользователи могут оставлять комментарии.

---

## 🛠️ Стек

### Frontend
- **React**, **Vite**
- **React Router** (роутинг)

### Backend
- **Node.js**, **Express**
- **Sequelize** (ORM), **PostgreSQL**
- **JWT** (авторизация), **bcrypt** (хеширование)
- **cors**, **cookie-parser**, **morgan**, **dotenv**

---

## 📱 Функциональность

### Главная страница
- Интерактивная карта
- Точки — сорта чая с координатами
- При наведении — название, при клике — переход на страницу чая
- Кнопки регистрации и входа

### Страница чая
- Название, место культивации, изображение, описание
- Блок комментариев
- Форма добавления комментария (только для авторизованных)

### Личный кабинет
- **Администратор:** управление сортами чая (CRUD), модерация комментариев
- **Пользователь:** список своих комментариев

---

## 🗺️ Ключевая особенность

Интеграция с **Leaflet** — мощной библиотекой для интерактивных карт. Это позволяет:
- Отображать чайные плантации по всему миру
- Масштабировать, перемещать карту
- Кликать по точкам для получения детальной информации

---

## 👥 Командная разработка

Проект выполняется группой. Все изменения проходят код-ревью через Pull Requests в ветку `dev`.

---

## 🌿 GitHub Flow

> **Основная ветка — `dev`. Все PR делаются в `dev`.**

1. Клонировать репозиторий
2. Создать ветку от `dev` под задачу
3. Часто делать коммиты
4. Перед PR обновить свою ветку через `merge dev`
5. Запушить ветку и создать Pull Request в `dev`
6. Другой участник проверяет и мержит
